## 这是什么

一个**把产业、企业、就业、生活放进同一张网里演算**的城市实验：

- **不是动画，是算出来的**：41 个真实主体、71 条产业链关系，同一起点任何人复跑结果一致。
- **冲击要有苗头才算数**：有现实依据的冲击才进入实验；纯假设的明确标注，只作压力测试。
- **每个数字都标得出处**：参数来自统计公报与公开报道，不玩黑箱。
- **普通人能玩，研究者能用**：一分钟命运实验面向大众；批量重跑、变量影响、主体访谈、正式研究档案面向专业用户。

## 项目背景

仲恺高新区是第一个内置 demo 世界（2025 真实公开数据）；模拟器本身属于任何想"重跑命运"的县镇与区域。

## 仲恺 2030 · 一分钟命运实验（大众入口，V1.2b）

首页从「产值目标 + 实验工具」改为**个人问题入口**：五年后的仲恺，你还会选择留在这里吗？

**四个生活身份** → 我在仲恺上班 / 我在仲恺开店 / 我在仲恺生活 / 我想留在仲恺。选择身份后进入一分钟实验：**你的问题 → 一场冲击发生（链主外迁+芯片断供，网络真实演化）→ 你的选择（三选一）→ 结果与分享卡**。

- **三决策选项全部映射到已有内核干预**：A 稳定生产 = 投资强度 +0.15；B 服务业重连 = 服务业配套 +0.15；C 人才长期 = talent 主体韧性 +0.1（**模型内近似，尚未实证标定，已注明**）。不宣称三者现实等价或可直接比较。
- **结果对比是模型内真实计算**：同一起点 7、同一双冲击，与「什么都不做」对照的存续 / 景气 / 风险 / 新合作 / 断裂变化；同配置任何人复跑结果一致。
- **边界诚实**：结果解释按身份给出「模型内可观察 + 可能传导机制」，明确标注**个人就业 / 小店营业额 / 房价 / 学位 / 医院未建模**；人才选项在 20 步冲击窗口内几乎不显效时，如实解释为「慢变量 + 模型边界」，不吹成速效药。
- **分享卡**：Canvas 生成「仲恺 2030 · 我的未来实验」PNG（身份 / 选择 / 关键数字 / 真实网络布局 / 起点与免责声明），一键下载；复制可复现链接（`#fate=身份&choice=选择&seed=7`），朋友打开自动重跑同一情景——只比「换作你会怎么选」，不比输赢。
- **专业工作台保留**：首页下半区仍是「快速探索 / 正式研究 / 八项研究能力」，科研功能未被遮挡。

## 使用流程

两种模式共用同一套计算内核：相同世界、参数、种子与事件序列，结果完全一致；区别只在**是否经过事前登记、修改是否受控、结论能否形成可审计的正式记录**。

| 分组 | 页面 | 主要作用 |
|---|---|---|
| 实验 | **概览** | 进入探索 / 正式研究，查看研究能力 |
| 实验 | **动态推演** | 产业协同活网络、五指标、播放/单步/时间轴、实验干预、自然语言注入、事件时间线 |
| 分析 | **蒙特卡洛** | 同种子批量重跑，五指标分布（mean/sd/P10/P50/P90） |
| 分析 | **敏感性分析** | 对投资强度/外部依赖/服务业配套/用地供给做 ±扰动，龙卷风图按敏感度排序 |
| 研究资料 | **主体档案** | 单主体经营状态、目标、记忆、局部关系（网络图中点节点亦可看抽屉） |
| 研究资料 | **决策档案** | 实验编号、预判、事件时间线、探索/正式报告，可导出 JSON |
| 研究资料 | **数据与证据** | 参数血统（A/B/C/D）、17 项公开指标来源、术语对照 |
| 高级设置 | **世界管理** | 仲恺基准恢复、CSV/JSON/TXT 导入、世界种子导出 |

**正式研究 · 实验准备与确认**（旧称「验模三门」，四步向导，探索模式不强制）：

1. **研究问题** —— 从已有实验选方向自动生成可编辑的问题草稿（不预设肯定结论），或自定义可证伪的一问；选择主要观测指标。
2. **网络结构审查**（旧称「审图门」）—— 三态：保留原始基准 / 发现漏项（先预览改动，确认后才生成世界副本 Draft-01，原始基准永不变）/ 对完整性不确定（保留并写入说明）。**不再强制查漏**。
3. **参数与证据**（旧称「参数门」）—— 逐项标记证据状态（来源已核对 / 未验证假设 / 待处理问题）并填写后续复核安排；允许带明确披露的假设做实验，但不能标为已验证。
4. **研究预判锁定**（旧称「落笔闸门」）—— 汇总摘要 → 生成实验编号（如 `ZK-20261012-001`），冻结世界、种子、问题与预判；锁定后预判不可原地覆盖，修改需生成修订记录或新实验。

**实验状态规则**：探索模式全放行；正式研究「已锁定」后，播放/单步/时间轴回放/计划内冲击允许并记录，未计划干预会先询问是否转探索分支，改世界/改参数会引导另开新实验——原档案永不丢失。
`TCL华星外迁` ｜ `芯片断供` ｜ `链主外迁` ｜ `增长动能 -0.2` ｜ `亿纬锂能停产`

死法词（外迁 / 停产 / 退链 / 破产 / 倒闭 / 流失 / 撤资 / 退场）——**链主外迁是这局最该压测的风险**。

## 三条边界（写在脸上）

1. **不是预测器** —— 不预测产值、不预测招商成败，只给叙事分布与结构。
2. **不是真涌现** —— demo 世界 41 主体是**可复现的弱涌现**，未达真实经济涌现量级。
3. **反事实不可验证，但参数可核对** —— "当年不引进某链主会怎样"无法重演；但每个参数都能回到统计公报核对。

## 导入你自己的世界

仲恺只是一份 **demo 基准模板**（41 主体 / 71 关系 / 15 因果链）。「世界管理」页可把它换成任意县镇/区域：

- **CSV 两表**（推荐）：
  ```
  [entities]
  # 名称,类型(anchor/oem/supplier/service/talent/capital/land/infra),权重1-3,说明
  中科智城,anchor,3,智慧城市总集成商
  [relations]
  # 起点,终点,关系,强度
  芯链半导体,中科智城,供货,0.8
  ```
  类型映射：链主/龙头→`anchor`、整机/终端→`oem`、配套/供应商→`supplier`、服务→`service`、人才→`talent`、资本/基金→`capital`、园区/载体→`land`、设施/电/路→`infra`。
- **JSON**：`{candidates:[{name,type,w,desc}], relations:[{a,rel,b,str}], params:{invest,external,service,land}}`（`examples/world_seed_zhongkai.json` 是完整的仲恺 demo 种子示例）。
- **TXT 报告**：内置词表按词频抽取主体、按类型自动连边。注意：这是**词表抽取，不是智能抽取**——报告里未命中词表的主体不会被识别，正式使用请用 CSV/JSON。

流程：上传或粘贴 → **解析预览**（类型/权重/关系可逐行修改、可删行）→ **生成世界** → 播放/蒙特卡洛/敏感性/访谈全部自动切到新世界。预置基线表仍是仲恺 400 局基准，可用于对比。
「**恢复仲恺基准**」一键回到内置模板；「**导出当前世界种子(JSON)**」可把自定义世界保存下来复用。

## 敏感性排序（给拍板用的东西）

龙卷风图（每档 24 局，扰动 ±0.15，README 历史基准；页面默认每档 40 局，Δ0.115/0.108/0.076/0.021，排序不变）按景气敏感度从大到小：

```
投资强度 Δ0.117  >  服务业配套 Δ0.109  >  用地供给 Δ0.074  >  外部依赖 Δ0.017
```

**投资强度与服务业配套是最关键、且几乎同等重要的抓手**——正对"投资崩、三产滞后"两大病灶；越靠前越该优先盯紧、或作为政策抓手。外部依赖影响最小（它主要抬升风险天花板，而非直接决定景气）。

## 实验干预压测（旧称：上帝视角）：链主外迁 + 芯片断供（受控实验）

用同源内核做**同世界同种子**的受控对比（120 局/场景，种子一致 → 世界构成逐局相同；tick5 注入 `TCL华星外迁` + `芯片断供`，比较四种政策）：

| 场景（各 120 局） | 景气 | 协同 | 风险 | 信心 | 存续 | 景气P10 | 风险P90 | 存续P10 |
|---|---|---|---|---|---|---|---|---|
| A 基线（无冲击） | 0.527 | 0.781 | 0.111 | 0.272 | 0.886 | 0.158 | 0.373 | 0.537 |
| B 双冲击 | 0.514 | 0.757 | 0.143 | 0.192 | **0.784** | 0.169 | **0.418** | **0.375** |
| C 双冲击+补生产性服务业 | **0.619** | 0.795 | **0.097** | 0.316 | 0.819 | **0.258** | **0.308** | 0.600 |
| D 双冲击+扭转投资 | 0.589 | 0.781 | 0.105 | 0.280 | 0.819 | 0.204 | 0.361 | 0.542 |

结论（模型内相对比较，非预测）：

1. **双冲击最伤的是产业链完整性，不是产值均值**：存续 −10.2 个百分点（0.886→0.784），风险尾部 P90 从 0.373 跳到 0.418。
2. **补生产性服务业（+集群）是止血最优解**：景气 +0.106（甚至超过无冲击基线 0.527→0.619）、风险 −0.046、景气坏局 P10 从 0.169 抬到 0.258。
3. **补位不是让企业不死，是让产业链不把伤扩散成系统性风险**。
4. **服务补位 ≥ 投资扭转**：同扰动幅度下，服务在景气与风险尾部上均优于投资；且补服务更快、更便宜。

复现：`node tests/stress_test.js`（提取同源内核，120 局 × 4 场景，约数秒）。

## 方法论：立场算，文本写

- **算的是立场**：固定规则 + 固定种子（mulberry32 PRNG），结果逐位可复现、可审计；行动概率是状态的连续函数。
- **写的是文本**：叙事模板按立场分档生成，不伪装成"模型算出来的命运"。
- **防正反馈无界**：景气/协同/风险均采用 logistic 饱和 + 中枢回归 + 风险天花板，投资崩作为**持续阻力**，存量经济具韧性（承载容量下限 0.15），避免端点饱和掩盖核心信号。

## 数据血统（A/B/C/D）

- 内置 **41 个真实主体**（八类）、**71 条产业链关系**、**15 条时序因果链**、**14 类产业冲击**、**7 类易漏角色**、**11 项参数**、**17 项公开指标**（均为仲恺 demo 世界数据）。
- 血统分级：**A** = 统计公报 / 管委会工作报告；**B** = 权威媒体 / 计划执行草案；**C** = 结构校准；**D** = 假设（需填检验日）。
- 链主（权重 w≥3：TCL 华星 / TCL 王牌 / 亿纬锂能 / 德赛西威 等）享经营保护、免疫随机消亡，但**上帝视角可令其外迁**。

主要来源：仲恺高新区 2025 年统计公报、管委会工作报告、2025 计划执行 / 2026 草案、经济运行简析、惠州市政府及权威媒体公开报道。

## 动态自适应产业网络（V1.2）

把"静态产业关系上的主体仿真"升级为"动态自适应产业网络仿真"——**关系随主体行为、冲击与政策自主建立、增强、削弱、断裂、重组，并反过来影响模型计算结果**。P0→P3 四阶段已全部交付。

### 机制（六种演化 + 两层分离）

| 机制 | 实现 |
|---|---|
| 主体进入 | 候选池未入场主体在景气期（景气≥0.45、风险≤0.35）以独立随机数流概率入场（单步≤2 家）；候选池外不虚构真实企业 |
| 关系建立 | 整机缺配套 / 配套缺链主订单、或断供后：在存活同类目标中按 能力×声誉×能量 打分，独立随机数流决定是否成交（成功率 .55，新合作 ≤ 断供损失数+1） |
| 关系增强 | 景气共振（景气>0.6 且双方能量>0.5）时合作强度 +0.02/步 |
| 关系减弱 | 需求萎缩（景气<0.4）时强度 −0.03/步，跌破 0.22 断裂 |
| 关系断裂 | 主体退出 / 移除 / 冲击波及 / 需求萎缩 → 关联活跃关系标记失效（记录 endedTick + 原因） |
| 网络重组 | 断供后自动寻找适格替代合作方，不强制恢复，允许持续萎缩 |

- **两层分离**：`产业事实网络`（史料/预设/补录，永不随动画改写）≠ `动态经营合作网络`（每步演化，反馈回经营）；新关系 `origin=simulated`，**不污染事实网络、不冒充真实商业联系**（补录边 origin=inferred）。
- **传播修正**：动态模式下已退出主体不再作为信号传播中间节点；信号传播只走 active 关系。
- **反馈耦合**：孤立主体（0 活跃关系）能量 −0.015/步；有 2+ 活跃关系 +0.008/步；生产性服务网络覆盖率润滑协同（+覆盖率×0.015）。
- **独立随机数流** `netRng`：网络匹配/进入/强度不扰动既有 Agent 随机序列（legacy 模式完全跳过新随机数）。

### 可视化与报告（P3）

- **三种视图**：结构模式（现状）/ 关系变化（只画新合作+失效）/ 风险传播（失效边 + 受影响节点红圈）。
- **网络演化时间轴**：滑块对应真实 20 步快照，只读回放不篡改轨迹；从旧时点继续 = 分支实验。
- **报告《产业网络演化与冲击传播分析》**：活跃主体 / 有效经营关系 / 新建关系 / 失效关系 / 孤立主体 / 最大连通分量 / 供应替代率 / 网络稳定用时 + 四时点快照（t0/5/10/20）+ 关系变化记录表 + 图例区分（事实蓝 / 模拟新合作绿 / 失效红虚线）。

### 动态模式怎么开

推演页「实验控制 → 网络演化」勾选"开启动态网络"，点「重置」生效。**关闭 = 静态对照模式，V1.0 结果逐位一致**（回归基线锁死）。

验证（`tests/verify_all.js` 第 6–9 段）：legacy 逐位回归 + 动态同种子可复现（关系序列/主体进入/快照对齐）+ 退出断链 + 传播修正 + 只读回放/分支语义 + 事实网络不被污染 + 新合作字段与上限合规 + 网络反馈审计记录。实测多种子 20 步：繁荣局网络保持、萧条局网络萎缩（允许变小不强制恢复）、中间局断链+替代并存——**网络改变模型，模型改变网络**。
