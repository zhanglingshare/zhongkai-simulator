# 县镇区域经济未来决策 · 命运重跑机器（zhongkai-simulator）

> 面向**县镇 / 区域经济协同**的决策模拟器：把产业链结构化成活的网络，让链主、整机、配套、服务、人才、资本、载体、设施八类主体自主演化。
> 内置首个 **demo 世界：仲恺高新区（2025 真实公开数据）**。
> **跑 1 次看故事，跑 1000 次看结构——每个参数都能回到统计公报核对。**

## 作者与背景

**张凌博士** · 高校副教授 · 广东省乡村振兴工作队成员 · 南粤优秀教师

本项目源自作者在高校教学与乡村一线工作的双重视角：**县镇**区域发展真正缺的不是"下一个风口"，而是**能反复推演、能回到数据核对、能让人拍板的决策工具**。把《山海经》世界模拟器的方法论（Seed → Graph → Agent → Simulation → Report）迁移到区域经济协同领域，就是本项目的起点——**仲恺高新区只是第一个基准 demo，模拟器本身属于任何想要"命运重跑"的县镇与区域。**

## 这是什么（项目介绍）

一个**单文件 HTML** 的**县镇区域经济决策模拟器** / 产业政策"风洞"。它以**仲恺高新区（demo）**为内置世界种子，
让**链主 / 整机 / 配套 / 服务 / 人才 / 资本 / 载体 / 设施**八类主体在投资、用地、外部需求约束下自主行动——
扩产、研发、就近配套、招商、融资，也会外迁、停产、退链、流失——并通过蒙特卡洛重跑与敏感性排序，
区分**什么是随机噪声、什么是系统结构**，为区域经济协同发展提供可审计的决策推演。

核心链路：

```
真实世界种子(统计公报 / 管委会工作报告 —— demo：仲恺高新区 2025)
   → 41 主体 · 71 产业链关系 · 15 时序因果链
   → Agent 人格 / 记忆 / 经营能量
   → 多轮行为模拟（私域决策 → 公域涌现）
   → 景气/协同/风险变化 · 外迁/退链/淘汰
   → 时间线 · 自动报告 · Agent 访谈
   → 蒙特卡洛重跑 · 敏感性龙卷风排序 → 稳定涌现路径
```

## 项目目标

1. **给县镇决策者一个"风洞"**：同样的世界跑 1 次看故事、跑 1000 次看结构，把"我感觉会崩"变成"坏局概率与触发条件"。
2. **每个数字可回查**：所有参数标注血统（A/B/C/D），C/D 级参数强制填"检验日"，到期对照公报——不玩黑箱。
3. **通用化**：仲恺只是 demo 基准，任何县镇/区域都可以通过「导入世界」上传自己的主体/关系/参数生成自己的世界。
4. **开源、可复现、可审计**：单文件零依赖，内核与 UI 分离，Node 断言 + 浏览器端到端双验证，任何人可复跑。

## 快速开始（如何使用）

**三步跑起来，全程不需要装任何东西：**

1. **下载** `zhongkai_simulator.html`（或直接访问在线版：[GitHub Pages 链接](https://zhanglingshare.github.io/zhongkai-simulator/zhongkai_simulator.html)，部署后可用）。
2. **双击打开**（任意现代浏览器，断网可用）。
3. **按顺序走一遍**：先到「② 验模三门」过三门并落笔锁定 → 回「① 推演」播放 20 步看世界演化 → 「③ 蒙特卡洛」重跑看分布 → 「④ 敏感性」看哪个抓手最重要。

想用自己的县镇/区域？到「⑧ 导入世界」上传 CSV / JSON / TXT 报告，一键生成你的世界（详见下文）。

## 使用流程（八个标签）

1. **推演** —— 区域产业协同网络、五指标（景气/协同/风险/信心/存续）、播放/单步/重置、上帝视角、自然语言注入。
2. **验模三门** —— 质量门，不过则报告锁定：
   - 门① **输入门 · Eigen 三问**：问题具体可证伪？接受只给叙事分布？值得跑？
   - 门② **审图门 · 图谱漏了谁**：至少检出一个漏项，勾选后**真补进图谱、连边、重建世界**。
   - 门③ **参数门 · 血统与检验日**：C/D 级参数必须填"检验日月数"，到期对照公报。
   - 三门过后 **🖋 落笔锁定**：写下你对这局结局的预判，写入决策档案，方可播放。
3. **蒙特卡洛** —— 同一世界重跑 N 次，输出五指标分布。
4. **敏感性** —— 对投资强度/外部依赖/服务业配套/用地供给做 ±扰动，龙卷风图按敏感度排序。
5. **访谈** —— 点击任一节点，基于其当前目标/位置/经营/行业地位/最近记忆做状态化访谈。
6. **决策档案** —— 落笔预判、时间轴打金标、复盘对照。
7. **数据血统** —— 每个数字的来源与参数血统（A/B/C/D），可审计。
8. **导入世界** —— 上传自己的数据/报告，把仲恺 demo 换成任意县镇区域。

**上帝视角 / 自然语言注入（离线解析，产业动词）**：
`TCL华星外迁` ｜ `芯片断供` ｜ `链主外迁` ｜ `增长动能 -0.2` ｜ `亿纬锂能停产`

死法词（外迁 / 停产 / 退链 / 破产 / 倒闭 / 流失 / 撤资 / 退场）——**链主外迁是这局最该压测的风险**。

## demo 世界：仲恺高新区自己说出的核心问题（Eigen Question）

**产值破 4000 亿之后，下一个千亿从哪来？**（demo 内置世界：仲恺高新区 2025）

| 指标（2025） | 值 | 信号 |
|---|---|---|
| 规上工业总产值 | 4037.12 亿（+12.2%） | 涨 |
| 工业投资 | **−23.6%**（2024 −31.5%） | 产值在涨、投资在崩 |
| 三产增加值 | +2.2%（工业 +14.0%） | 服务业几乎没动 |
| 超高清显示 | 1034.5 亿（+6%，2024 +23.6%） | 刚破千亿就失速 |
| 智能终端 | 1345.8 亿（+11%） | 增速回落 |
| 能源电子 | 811.6 亿（+18.7%） | 唯一高增的第三极 |

答"靠投资（招商）"，后面全是招商；答"靠第三极能源电子"，后面全是能源电子。不回答，所有努力空转。

## 三条边界（写在脸上）

1. **不是预测器** —— 不预测产值、不预测招商成败，只给叙事分布与结构。
2. **不是真涌现** —— demo 世界 41 主体是**可复现的弱涌现**，未达真实经济涌现量级。
3. **反事实不可验证，但参数可核对** —— "当年不引进某链主会怎样"无法重演；但每个参数都能回到统计公报核对。

## 导入你自己的世界（v0.8.1）

仲恺只是一份 **demo 基准模板**（41 主体 / 71 关系 / 15 因果链）。第八个标签页「⑧ 导入世界」可把它换成任意县镇/区域：

- **CSV 两表**（推荐）：
  ```
  [entities]
  # 名称,类型(anchor/oem/supplier/service/talent/capital/land/infra),权重1-3,说明
  中科智城,anchor,3,智慧城市总集成商
  [relations]
  # 起点,终点,关系,强度
  芯链半导体,中科智城,供货,0.8
  ```
  类型映射：链主/龙头→`anchor`、整机/终端→`oem`、配套/供应商→`supplier`、服务→`service`、人才→`talent`、资本/基金→`capital`、园区/载体→`land`、设施/电/路→`infra`。
- **JSON**：`{candidates:[{name,type,w,desc}], relations:[{a,rel,b,str}], params:{invest,external,service,land}}`（`examples/world_seed_zhongkai.json` 是完整的仲恺 demo 种子示例）。
- **TXT 报告**：内置词表按词频抽取主体、按类型自动连边。注意：这是**词表抽取，不是智能抽取**——报告里未命中词表的主体不会被识别，正式使用请用 CSV/JSON。

流程：上传或粘贴 → **解析预览**（类型/权重/关系可逐行修改、可删行）→ **生成世界** → 播放/蒙特卡洛/敏感性/访谈全部自动切到新世界。预置基线表仍是仲恺 400 局基准，可用于对比。
「**恢复仲恺基准**」一键回到内置模板；「**导出当前世界种子(JSON)**」可把自定义世界保存下来复用。

## 运行 400 次看结构（demo 真实基线）

400 次蒙特卡洛真实基线（base seed = 7，格式 mean / sd / P10 / P50 / P90，由本页面同源内核重算）：

| 指标 | mean | sd | P10 | P50 | P90 |
|---|---|---|---|---|---|
| 景气 abundance | 0.5367 | 0.2288 | 0.1920 | 0.5760 | 0.8647 |
| 协同 order | 0.7824 | 0.0882 | 0.6305 | 0.8253 | 0.8474 |
| 风险 disaster | 0.1087 | 0.1361 | 0.0180 | 0.0320 | 0.3562 |
| 信心 mood | 0.2774 | 0.2957 | −0.2310 | 0.4085 | 0.5642 |
| 存续 survivors | 0.8853 | 0.1737 | 0.5833 | 1.0000 | 1.0000 |

五指标呈**真分布、不顶格、不归零**：景气中位 0.58，但坏局 P10 仅 0.19；风险中位低（0.03）但尾部 P90 跳到 0.36；坏局约四成主体退场。

## 敏感性排序（给拍板用的东西）

龙卷风图（每档 24 局，扰动 ±0.15）按景气敏感度从大到小：

```
投资强度 Δ0.117  >  服务业配套 Δ0.109  >  用地供给 Δ0.074  >  外部依赖 Δ0.017
```

**投资强度与服务业配套是最关键、且几乎同等重要的抓手**——正对"投资崩、三产滞后"两大病灶；越靠前越该优先盯紧、或作为政策抓手。外部依赖影响最小（它主要抬升风险天花板，而非直接决定景气）。

## 上帝视角压测：链主外迁 + 芯片断供（受控实验）

用同源内核做**同世界同种子**的受控对比（120 局/场景，种子一致 → 世界构成逐局相同；tick5 注入 `TCL华星外迁` + `芯片断供`，比较四种政策）：

| 场景（各 120 局） | 景气 | 协同 | 风险 | 信心 | 存续 | 景气P10 | 风险P90 | 存续P10 |
|---|---|---|---|---|---|---|---|---|
| A 基线（无冲击） | 0.527 | 0.781 | 0.111 | 0.272 | 0.886 | 0.158 | 0.373 | 0.537 |
| B 双冲击 | 0.514 | 0.757 | 0.143 | 0.192 | **0.784** | 0.169 | **0.418** | **0.375** |
| C 双冲击+补生产性服务业 | **0.619** | 0.795 | **0.097** | 0.316 | 0.819 | **0.258** | **0.308** | 0.600 |
| D 双冲击+扭转投资 | 0.589 | 0.781 | 0.105 | 0.280 | 0.819 | 0.204 | 0.361 | 0.542 |

结论（模型内相对比较，非预测）：

1. **双冲击最伤的是产业链完整性，不是产值均值**：存续 −10.2 个百分点（0.886→0.784），风险尾部 P90 从 0.373 跳到 0.418。
2. **补生产性服务业（+集群）是止血最优解**：景气 +0.106（甚至超过无冲击基线 0.527→0.619）、风险 −0.046、景气坏局 P10 从 0.169 抬到 0.258。
3. **补位不是让企业不死，是让产业链不把伤扩散成系统性风险**。
4. **服务补位 ≥ 投资扭转**：同扰动幅度下，服务在景气与风险尾部上均优于投资；且补服务更快、更便宜。

复现：`node tests/stress_test.js`（提取同源内核，120 局 × 4 场景，约数秒）。

## 方法论：立场算，文本写

- **算的是立场**：固定规则 + 固定种子（mulberry32 PRNG），结果逐位可复现、可审计；行动概率是状态的连续函数。
- **写的是文本**：叙事模板按立场分档生成，不伪装成"模型算出来的命运"。
- **防正反馈无界**：景气/协同/风险均采用 logistic 饱和 + 中枢回归 + 风险天花板，投资崩作为**持续阻力**，存量经济具韧性（承载容量下限 0.15），避免端点饱和掩盖核心信号。

## 数据血统（A/B/C/D）

- 内置 **41 个真实主体**（八类）、**71 条产业链关系**、**15 条时序因果链**、**14 类产业冲击**、**7 类易漏角色**、**11 项参数**、**17 项公开指标**（均为仲恺 demo 世界数据）。
- 血统分级：**A** = 统计公报 / 管委会工作报告；**B** = 权威媒体 / 计划执行草案；**C** = 结构校准；**D** = 假设（需填检验日）。
- 链主（权重 w≥3：TCL 华星 / TCL 王牌 / 亿纬锂能 / 德赛西威 等）享经营保护、免疫随机消亡，但**上帝视角可令其外迁**。

主要来源：仲恺高新区 2025 年统计公报、管委会工作报告、2025 计划执行 / 2026 草案、经济运行简析、惠州市政府及权威媒体公开报道。

## 可复现性与测试

内核代码以 `/*KERNEL-BEGIN*/ … /*KERNEL-END*/` 包裹、不依赖 DOM，可被 Node 提取做命令行验证。
当前版本 **43 项断言全部通过**（`node tests/verify.js`），覆盖：

- 数据规模（41 / 71 / 15 / 8 / 14 / 7）；
- 同种子两次结果**逐位一致**、异种子结果不同；
- 蒙特卡洛五指标真分布、不顶格、不归零；
- 布局 **0 重叠**（最近间距 24.3px）；
- 自然语言解析（链主外迁 / 芯片断供 / 参数扰动 / 主体移除）；
- 门②补漏（24→26、连边≥6）、敏感性返回 4 行并降序；
- **导入世界**：CSV / JSON / TXT 三种解析、自定义世界可 step 20 轮、可跑蒙特卡洛、JSON 参数注入、恢复仲恺基准 41/71/15 精确还原。
