# 仲恺区域经济沙盘 · zhongkai-simulator

一个可以在浏览器里打开、断网也能运行的仲恺高新区产业沙盘。把 2025 年的公开底数铺成一张可以点、可以拖、可以反复比较的桌面，让"这个区的结构长什么样、哪些环节会先受影响"变成看得见的东西。

不是一份报告，是一张能动手的底图。

## 打开方式

下载 `zhongkai_simulator.html`，双击用任意现代浏览器打开。不需要安装，不需要联网，不上传任何数据。

## 八个入口

| 入口 | 看什么 |
|---|---|
| 推演 | 41 个主体、71 条产业关系铺在图上；景气、协同、风险、信心、存续五个读数随时间走 |
| 校验 | 动手播放之前，先把这一局的前提写清楚 |
| 重复运行 | 同一个起点反复跑，看五个读数最终落在什么区间 |
| 条件影响 | 投资强度、外部依赖、服务业配套、用地供给，改动哪一个，结果变化最大 |
| 点开一个主体 | 看它此刻的目标、位置、经营状况与最近动作 |
| 决策记录 | 先写下自己的判断，事后再对照 |
| 数字来源 | 每一个数字点开都能看到它从哪里来 |
| 换一个区域 | 上传自己的数据，把仲恺换成你的县、镇或园区 |

## 数据来源

全部来自公开渠道：统计公报、管委会工作报告、政府门户与主流媒体公开报道。页面内每个数字标注来源与时间；查不到的留空并注明"暂缺"，不填默认值假装查到。

## 边界

不预测具体产值、招商成败或企业命运；页面上给出的都是特定条件下的相对结果，不是现实预言。不构成投资或经营建议，也不替代任何官方决策。
