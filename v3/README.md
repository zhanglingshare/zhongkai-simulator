# 仲恺产业风洞 V3 · 决策实验工作台（试验分支）

**目的：重构 UI/UX，不更改模拟内核。** V3 使用根目录原有的 `model.js`，不复制、不修改多智能体模型、参数定义或数据同步管线。

## 结构

- `index.html`：单页决策工作台。左侧输入，中央真实产业网络/模型快照曲线/时间线，右侧模型指标与主体观察；底部 A/B 情景对比，可进入专注模式。
- `style.css`：独立的桌面/平板/手机样式。手机端提供设置、观察、洞察、对比四个切换区。
- `app.js`：只负责界面编排。复用 `Sim`、`layoutForce`、`render()`、`sim.interview()` 等原有能力。
- V2 的蒙特卡洛、敏感性、数据导入、验模三门、研究档案仍保留原页，并从 V3 导航直达；本轮不冒险重写其操作机制。

## A/B 对照的真实计算方式

1. A：`new Sim(seed, {...sim.params})`，按照引擎演化到 20 步；
2. B：独立的 `new Sim(seed, {...sim.params})`，在 t0 执行模型已支持的 `shock(type)`，运行相同步数；
3. 显示 A/B 两张网络图，共用从 A 的主体结构计算的节点坐标，确保不是因为布局变化造成错觉；
4. 从两个仿真实例的 `state` 和 `survivors()` 计算五指标差值，绝不写入硬编码演示数值；
5. 当前主工作区的 `sim` 不受 A/B 对照修改。

**方法学限制：** 两个实例使用相同种子，但冲击可能改变 PRNG 消耗顺序，因此不是严格配对的因果估计；模型模拟概率不等于现实发生概率。

## 保留的完整功能

既有的时间线播放/单步/重置、冲击注入、状态扰动、主体移除、离线规则解析、主体访谈仍由原 `model.js` 处理。V3 不新增伪滑块或假参数逻辑。

## 验证清单（合并前）

- 桌面 1440px、平板 1024px、手机 390px/360px 下看所有四个工作区，确认无横向溢出；
- 当前局：注入冲击、单步、播放/暂停、进度条、重置与随机种子重载；
- 网络节点鼠标点击与键盘 Enter/Space 可查看主体，节点聚焦不遮挡网络；
- 指标演化由当前局真实 `sim.snapshots` 生成，时间线取模型事件；
- A/B 用同一个 seed 模拟 20 步；结果展示 A/B 指标值与 B-A；更改类型或种子会提示对比过期；
- 专注对比模式可打开并用 Esc 关闭；
- V2 工具、数据和模拟核心文件保持可访问，`model.js` 的 Git diff 必须为空。

当前阶段：**实验 UI 的可审查源码，非线上正式版。** 合并前需要真实浏览器端到端测试与用户视觉验收。

## V3.2 · 多种子稳健性与研究留痕

- 在 V3.1 的同步 A/B 对比下增加 **24 / 48 / 96 组随机种子**的模型内重复实验。每组生成两个原始 `Sim` 实例，使用相同参数和种子，B 于第 0 步注入已有的 `shock(type)`，分别演化 20 步。
- 对 **景气、协同、风险、信心、存续率** 的 B−A 差值绘制五张采样分布图，展示每组结果点、P10、P50、P90 和 B>A 的样本计数。图表横轴各自标注刻度，分布不是现实经济预测概率，也不是频率学置信区间。
- 计算每八组主动让出 UI 线程，实时更新进度并允许中止；输入设置变化时取消当前计算并标记旧结果。
- 新增 **“直接对比 A/B”** 的输入区快捷操作，手机端自动切到对比工作区。
- 可下载可审计的 **研究 JSON**，记录已计算情景的种子、冲击、参数、历史状态、最终值，以及可选的多种子样本。即使用户随后修改输入，导出的研究问题仍采用运行 A/B 时保存的版本。
- 仅增加 V3 的 UI/编排层代码和其浏览器测试；原 `model.js`、豆包同步数据、V2 均未改动。

### 稳健性研究的严格解释边界

1. **相同种子不是严格的因果配对：** 冲击可能改变后续随机数消耗和事件序列；这里仅观察模型内结果随种子改变是否稳定。
2. **样本计数不是现实概率：** B>A 的组数比例仅为该批模拟种子的实验频数，不代表当地产业未来的真实事件概率。
3. **P10–P90 不是预测区间：** 它只描述指定种子和模型参数下的模拟输出分布。
4. **模型指标与经济统计口径不同：** 景气、协同等指数不是 GDP、增加值或真实企业存续率的直接预测。


## V3.3 科学验证与证据台（独立的前端校验工作区）

新增 [verification.html](verification.html)、`verification.js`、`verification.css` 与 `validation-core.js`，不修改原始模拟算法：

- **每日数据审计：** 实时读取根目录 `hot.json` / `life.json`，检查数量、日期、HTTPS 链接、数据结构和镇街来源缺失。所有“已核验”均仅表示源文件自带标记，**本工具不自动访问第三方来源认证真实性**；
- **模型参数血统：** 只读拉取根目录 `model.js`，解析 `PARAM_LINEAGE` 和 A/B/C 等级，计算源码 SHA-256 指纹，明确“级别 A 不等于模型预测通过验证”；模型 2025 内置指标不是豆包每日更新过的参数；
- **历史留出集门槛：** 用户上传 `zk-backtest-v1` JSON，需具备归档预测、独立观测链接、冻结映射、版本 SHA、至少八条记录及至少三个观测日期，并严格检查校准截止、预测日期、观测日期的先后顺序与数值范围。不合格数据不评分；
- **评分边界：** 合格结构仅输出*提供者自报材料*的 MAE / RMSE 与朴素基线比较。程序并未自动核验归档真实性或完成参数拟合；
- **方法学规程：** [validation-protocol.md](validation-protocol.md) 明示历史数据泄漏、时间映射与未来真实外部校准的前置条件。

GitHub Actions 执行 `v3/tests/validation.spec.cjs` 检查泄漏门槛，并使用 Playwright/Chrome 在桌面和手机视口对实验区、证据台和历史留出导入执行实测。**目前没有可供认证的独立留出实证数据，历史预测能力仍未验证。**

## V3.8 全息产业风洞 · 三维交互主舞台

**根本改变：全息三维世界取代研究表单成为首页第一屏。** 保留 V3.7 风险/增长工作台和 V3.6 科学验证能力，但把它们放在三维主舞台之后。

- **真正三维渲染，不使用静态三维假图片：** v3/holo-render.js 使用浏览器 WebGL GLSL shader 进行空间透视与节点/关系渲染，支持鼠标拖动旋转、滚轮或按钮缩放、触屏拖动、双指捏合及点击主体。
- **无外部渲染 CDN 依赖：** 原生 WebGL shader；WebGL 不支持时使用 Canvas2D 按同一三维相机做透视投影的 2.5D 交互降级。
- **严格来源于原模型：** v3/holo-core.js 从 Sim.agents、Sim.edges、每个 tick 的 _snap() 读取真实模型内节点、存续、能量和关系类型。历史/预设边、同类亲和边、同域接触边采用不同视觉层级，模型中不存在的边不渲染。
- **三维坐标不是经济事实：** 坐标使用确定性散布算法，对相同模型主体稳定复现；它不是惠州地图、实际地理坐标、距离或供应链交易值。亮线流动仅为示意连通关系的装饰，不表示真实物流或资金量。
- **模型冲击的真实时序：** 顶部风险按钮注入“链主外迁”、增长按钮注入“技术突破”，调用已有 Sim 的 A/B、按模拟 tick 读取 B 场景真实快照。支持播放、暂停、手动拖动时间轴；重设参数后清空旧动态实验。
- **节点检查：** 点击节点显示其原模型类型、存续状态、能量值、历史与假设的模型关系数；不把推断边叫作真实合同。
- **交互优先：** 桌面和手机可直接从首屏进入风洞，并通过“进入研究工作台”链接访问旧版完整严谨工具。
- **科学边界：** 仍是公开资料上的条件性模型实验，不代表官方判断、GDP 预测、已校准概率；各项 WebGL 视觉冲击不可替代科学验证。

验收新增 v3/tests/holo.spec.cjs：确定性三维坐标、真实模型拓扑、动态状态变化、空间投影与参数边界。Playwright Chrome smoke 增加 1440px/390px/360px 的真实三维首屏、风险和增长场景、同步时间轴与过期结果处理。


## V3.8 全息遮挡修复：三端可视化净空

实机反馈：旧 V3.8 的 WebGL 画布铺满整块首屏，而标题、右侧指标、下方操作浮层覆盖了全息网络，手机尤为明显。修复采用真正的布局隔离，而不是继续叠加绝对定位的偏移量。

- 新增独立 .holo-world 三维画布容器。桌面以 CSS Grid 将标题、三维空间、模型指标和底部控制栏放在不相交的区域；全息图不再被遮住。
- 手机和窄屏改为纵向 Grid：标题与场景按钮 → 单独的可拖动三维网络 → 四项指数 → 需要时出现的主体详情 → 时间轴和相机按钮。
- 缩短默认摄像机距离到 5.1，保证世界在专属视口内充分展开；旋转、缩放和交互仍使用原 WebGL/Canvas2D 实际节点坐标。
- 主体详情只在手机用户点击模型节点后出现，占自己的行，禁止默认遮挡网络。
- Chrome 回归新增真实几何矩形检测，桌面1440和手机390/360上，.holo-world 与标题、指标、控制区及主体详情交叠面积必须为零。继续验证模型交互、测量与其它页面。

不改 Sim/model.js，也不修改任何公开来源或历史资料。此补丁只修复视觉结构与三维相机距离，不产生未经验证的新增经济结论。
