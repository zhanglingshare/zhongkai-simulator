# V3.6 模拟状态—现实观测测量协议（Measurement Bridge）

状态：**测量假设登记、显式时间映射、样本内可复算诊断已实现。真正的测量校准、独立外部验证未完成。**

## 核心科学边界

现有 `model.js` 的 `Sim` 输出五种状态：景气 `abundance`、协同 `order`、风险 `disaster`、信心 `mood`、存续率 `survivors`。这些都是模型内部的潜变量或衍生状态，不是原始官方经济统计。

2019—2025 年度观测文件 `observations/annual-2019-2025.json` 保存了真实统计总量和增速及其出处，但没有“每一模型时间步 = 一个日历年”的实验设定。现有模型编码了截至 2025 年的产业历史事件及数据，2025 年不能充当干净的外部留出预测。

因此 **“有可用统计指标” ≠ “测量公式已校准” ≠ “现实预测通过验证”**。

## 首批候选假设（不是固定事实）

| 模型状态 | 可提议的外部测量 | 识别风险 |
| --- | --- | --- |
| 景气 `abundance` | 规上工业增加值同比、GDP 可比价同比 | 产业增长或 GDP 同比不直接测量潜在景气；统计频率、政策和产业覆盖不同 |
| 协同 `order` | 暂无 | 需要同口径本地采购率、企业交易网络/关系强度等可独立核验数据 |
| 风险 `disaster` | 工业投资同比（极弱反向候选） | 投资受建设周期、政策和宏观周期影响，不能直接表征断链或灾害 |
| 信心 `mood` | 暂无 | 需要重复抽样企业信心调查及量表一致性 |
| 存续率 `survivors` | 暂无 | 需要同口径企业进入队列与存续退出数据 |

`measurement-core.js` 只注册以上 3 个弱代理候选，不允许用户把现价 GDP 总量与任意 [0,1] 潜变量强行配对后声称通过校准。

## 可检验而不误导的第一步：显式测量协议

研究者导入 V3.5/V3.2 情景实验导出文件（`zhongkai-v3-research-1`），从其 *A 情景* 的 `baselineHistory` 获取真实运行的逐步模型内部状态；人工显式登记每一对 `{year,tick}`，登记样本内拟合截止年及候选现实观测。

### 暂时的测量方程（诊断示例，不是经济理论已证实）

\[
y_t=\alpha+\beta z_{g(t)}+\varepsilon_t,
\]

- `y_t`：公报公布的某项同比增速（单位：%），保留该年原始来源及修订标记；
- `z_{g(t)}`：模拟器内部状态（无量纲），`g(t)` 是研究者填写的时间步映射假设；
- `alpha` 和 `beta`：**仅在截止年及之前的配对数据**上通过普通最小二乘拟合；
- 截止年之后的历史数据只被标为“事后回放”，不重新参与拟合；结果展示 *描述性残差*，不称作独立预测误差。

程序设置硬门槛：至少 4 对日历年—模型步，一对年度和模型步只能使用一次，年份和时间步均应严格上升；样本内至少 3 年、后段至少 1 年；缺失真实统计、来源不全、无模型快照、模型数值非有限、样本内指标近乎常数时不得拟合。

任何导出的结果均明确写入 `validationPassed:false`、`calibrated:false`，保留全部已配对年份、模拟步骤、原始观测及其来源、拟合范围、参数和声明。这只实现 **reproducibility（计算可复算）**，尚未实现 **empirical validity（测量有效）**。

## 现阶段禁止的操作

1. 不能把 `abundance=0.7` 解释成 `GDP+7%`，除非固定、独立验证的测量方程和外部观察许可该解释。
2. 不应把 `Sim` 的 `Kcap` 解释成土地、电力、水或排污工程容量。
3. 不能默认 `tick 0…20` 的单位是年度或季度；目前没有可验证的日历映射。
4. 不能将已经编码 2025 事件的 `model.js` 和 2025 官方经济数据做一组配准后称为真实历史回测。
5. 不能将后段历史回放的 MAE/残差表述为“样本外准确率”，原因不仅是测量系数不泄漏，还涉及模型构建和特征中的历史信息泄漏。
6. 不能将从非预先注册且受选择偏差影响的样本内相关性称为因果效应。

## 升级为真正的外部验证

1. **观测协议冻结：** 选择一种可独立采集的年度/季度指标，说明它为什么能测量某个模型状态，事先确定频率、缺失处理、统计版本、观察期。
2. **时间机制确定：** 用独立机制确定模型步与日历/预测期映射，而不是看到目标年度结果后重新挑选。
3. **模型及转换冻结：** 在预测目标揭晓前冻结 Git SHA、模型参数、种子或种子分布、测量系数与事先规定的政策情景。
4. **不可篡改的预测归档：** 对原始预测工件存时间戳与哈希，并使用能被独立核对的不可变存储或签名记录。仅凭填写 URL 无法证明当时已经发布。
5. **预设基线：** 同口径比较上一期持平、历史均值等朴素基线，严格按发布时点维护数据 vintage。
6. **滚动、盲测、反馈：** 在真正未来发布的官方数据上评估误差和符号稳定性，记录失败案例；拒绝以模型本身出现的历史数据再次自证。

`measurement-core.js` 的 `futureProtocol()` 输出初始预注册 JSON **空白模板**，并明确标记“未满足”。它不自动生成经济预测。
