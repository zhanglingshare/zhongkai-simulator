# V3.4 仲恺公开统计年度观测登记册（2022—2025）

**状态：已摘录来源、可追溯、部分年份待查政府原始公报；未作参数校准，不满足独立回测条件。**

## 资料范围

- 数据文件：`annual-2022-2025.json`（schema: `zk-annual-observations-v1`）。
- 4 个完整年度、9 类经济指标、36 条原始数值记录，每条含原始年份、单位、源文件 ID、核验状态和必要备注。
- 每个 `sources` 条目保留发布机构、链接、来源类型（官方门户 `government_portal`／第三方转载 `third_party_mirror`）。
- **官方门户原文**：2024 年仲恺高新区年度统计公报。2023 年、2025 年的部分总量和增长率有政府官网佐证，但多数年度公报数值是从第三方转载摘录。
- 不对缺失年份插值、不把估算数填作观测值、不用相邻两年的现价 GDP 反推官方可比价同比增速。

## 年度指标

| 键名 | 统计内容 | 单位 / 口径 |
|---|---|---|
| `gdp_current` | 地区生产总值 | 亿元，现价总量 |
| `gdp_real_yoy` | 地区生产总值同比增长 | %，官方公布可比价增速 |
| `primary_current` | 第一产业增加值 | 亿元，现价总量 |
| `secondary_current` | 第二产业增加值 | 亿元，现价总量 |
| `tertiary_current` | 第三产业增加值 | 亿元，现价总量 |
| `industry_growth` | 规上工业增加值同比 | %，官方报道增速 |
| `industry_invest_growth` | 工业固定资产投资同比 | %，官方报道增速 |
| `retail_current` | 社会消费品零售总额 | 亿元，名义总量 |
| `budget_current` | 地方一般公共预算收入 | 亿元，名义总量 |

## 已发现的核对点

1. **2025 财政预算收入**：2025 年转载公报报出收入 53.91 亿元、同比增长 3.7%；2024 年官方公报为 44.93 亿元。两个披露总量按算术计算约增长 20.0%，与文字中的 3.7% 不一致。可能来自基期修订、统计口径变化或转载问题，未经官方确认，不得擅自更正任一数值。
2. **GDP 统计口径**：每年 GDP 和三次产业增加值使用现价；公报同比使用可比价。名义总量之间的年变动不等于官方公布的实际增长率。
3. **2022、2023 与部分 2025 来源**：由于未检索到可逐页核对的官方原公报，当前部分数据使用第三方转载文本；保持 `mirror_needs_primary` 状态，不写作“官方原文已审核”。
4. **2024 GDP 分项与总量**：四舍五入可能出现 0.01 亿元量级误差，验证器容许 0.03 亿元容差。
5. **已知模型数据依赖**：当前 `model.js` 参数和历史情景包含 2025 年事件、指标，不能拿同一时期的 2025 年公开数据自称独立留出验证。

## 绝不自动完成的步骤

V3.4 页面不会将 GDP、工业增长率、工业投资等观测直接替换模型中的 `abundance`、`disaster`、`invest` 参数。这种替换既不满足量纲一致性，也无法解释内部 20 个演化时间步如何对应年度经济变化。

真正校准必须先：

1. 明确要预测哪个可观测量，并事前冻结从模型状态到该观测量的映射及参数版本；
2. 扩充可比年度或更高频观测；只掌握 4 个年度远不足以支撑现有多参数模型的稳定辨识及独立留出；
3. 划分训练/校准期与未来留出期，在看到结果之前归档预测；
4. 根据冻结的样本与基线做误差评估；不能复用内置模型的历史参数来证明预测有效。

完整留出集规则参见 `../validation-protocol.md`。2026 年任何新观测须追加来源和归档日期，不能默默覆盖过去年份。

## 可执行质量测试

`node ../tests/observations.spec.cjs` 会验证 36 条观测、单位、来源引用、年份去重、GDP 分项一致性、缺失值处理、财政数值预警及“校准阻断”门槛。GitHub Actions 使用 Chrome 在 1440px、390px、360px 实际视口测试趋势与来源浏览。


## V3.5 2019—2021 增量归档与滚动基线（2026-10-15）

在不覆盖旧版数据的前提下，新建 `annual-2019-2025.json`。2019 的来源是[政府工作报告](https://www.hzzk.gov.cn/zzgxqgwhmhwz/zwgk/zfgzbg/content/post_3883587.html)（仅含四项原文明确的指标）；2020 是[2020 年公报转载](https://maptable.com/tjgb/2020/%E6%83%A0%E5%B7%9E%E5%B8%82/%E4%BB%B2%E6%81%BA%E5%8C%BA/report/hui-zhou-shi-2020-nian-zhong-kai-gao-xin-qu-guo-min-jing-ji-he-she-hui-fa-zhan-tong-ji-gong-bao)（原件仍待认证）；2021 是[官方经济运行简况](https://www.hzzk.gov.cn/zzgxqgwhmhwz/zwgk/qt/tjxx/content/post_4545227.html)。7 年、58 条记录，未找到的条目仍缺失。

**重大口径断点**：2019 政府报告记载零售总额 76.6 亿元，2020 公报转载记载零售总额 126.90 亿元但同比 -8.3%；在修订链核对之前不能连线、不能据此拟合。原 V3.4 对 2025 财政收入不一致的警示仍然存在。

`benchmark-core.js` 的过去一年增速与历史均值比较是**事后、使用非逐期归档的历史版本回溯重建**：目标年仅使用之前年度的值，不含未来数值，但观测 vintage/统计修订未复原，不能称为真实 2019—2025 事前预测、独立外样本检验或当前 `Sim` 核心校准。新增 `v3/tests/benchmark.spec.cjs` 验证不会让目标年信息进入其基线。
