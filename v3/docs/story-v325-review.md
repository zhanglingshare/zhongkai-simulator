# V3.25 故事版：同一步的可见对比

本轮只修改故事首页、故事实验页及它们专用的展示组件。专业版、经典版、证据页、模型、边表和各项数据保持 V3.24 发布内容。

## 三处修订

| 观察到的阅读阻力 | 修订后的行为 | 验证 |
| --- | --- | --- |
| 当前数值突出，两条路径的差被埋在小字中 | 未改变、改变后与净差并排；角色/连线可切换；两侧使用同一初始满格 | 每一步可见数字直接与原模型快照计数核对 |
| 时间线像普通细进度条，不易感到手在控制变化 | 大触点、当前整数步浮签、真实关键步标记；拖动同步改画面、数量和角色，松手暂停 | Chromium 原生触摸拖动、鼠标拖动及停止回放断言 |
| 揭晓后仍被设置区分散注意 | 同一舞台展开至全宽，桌面以大网络配侧边控制，手机上下布局；保留换条件入口，长按只换路径，不换镜头与时间步 | 手机舞台几何、同镜头快照与设置返回/旧结果清空断言 |

## 反直觉结果核查

原模型 seed=7、41 个角色、TCL华星退出：第20步未改变路径38个角色，改变后39个。只在改变后退出的是TCL华星、电池工程师；只在改变后仍运转的是软件信息、物流企业、人力资源服务。因此净差是3−2=+1。

从初始化完成后包裹原有rng仅计调用次数：第1步两条路径分别调用62与61次；20步累计965与878次。主体退出后行动、能量与随机数消耗都会分化。不能据此把+1解释为“链主退出有益”或确认某个因果机制。产品提供组成差异与简短解释入口。

## 验证边界

自动化覆盖桌面、390与360像素手机，减少动态效果、2D回退、键盘/鼠标/原生触摸、真实模型快照、24起点重复与版本隔离。浏览器截图用于版式检查。这不是现实预测，也未进行真人可用性研究。
