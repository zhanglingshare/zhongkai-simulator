# 仲恺产业风洞 V2（界面层）

本目录仅包含页面和 CSS。沿用根目录原始 `model.js`、`hot.json`、`life.json`，不复制或修改模型计算、数据更新流程。

- `index.html` 为工作台首页。
- `run.html`、`montecarlo.html`、`sensitivity.html`、`gates.html` 等页面保留原有的所有模型交互 DOM ID、按钮事件及引擎绑定。
- `today.html`、`towns.html` 分别读取根目录每日更新的 `hot.json`、`life.json`。
- `base.css` 为原 `model.css` 的样式副本，去掉误包含的 HTML `style` 标签；`theme.css` 是 V2 视觉与手机响应式覆盖层。
- 旧版根目录页面完全不动。任何界面问题可从每页的“查看原版页面”返回旧版。

## 合并前验收

1. 手机宽 360/390px 与桌面宽 1440px，确认导航可操作、无横向溢出。
2. 动态推演：单步、播放、暂停、重置、注入冲击、点击主体。
3. 研究准备：三门勾选、补入角色、落笔锁定。
4. 蒙特卡洛、敏感性：运行、结果分布可见。
5. 数据与证据：导入 CSV/JSON、生成世界、导出种子。
6. 每日动态与各镇生活：新闻及统计更新信息正确显示，断网时给出可理解的失败提示。
7. 确认 `model.js`、`hot.json`、`life.json` 的 git diff **为空**。

**注意：不同页面原有模拟运行态并不自动持久化。** 这一轮不修改其会话保存行为。
